Procedure

create a new Excel file with the data of the TAB "Call Summary per Line".
Do not include the header line and paste the data a data-only, no formatting
Make sure there are no rows hidden in the source Excel file
The new created file should have the name source.xlsx

Put this file "source.xlsx" in the target directory on the correct sever
For this see the file "mobile_phone.conf"

Start the script to import the data "load_monhly_usage.sh"
